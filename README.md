# Curso Fullstack — Material de Frontend

Material didático da **metade Frontend** do curso presencial **Programação Fullstack** (UNIESP),
prof. Kelson Almeida. Do zero (HTML) até consumir, em React, a mesma API que o aluno construiu
no backend.

Site estático, modular, sem build — abra `index.html` no navegador (recomendado: extensão
**Live Server** do VSCode).

## Estrutura
- `index.html` — hub com a apresentação do que será construído
- `sobre/` — sobre o professor
- `capitulos/NN-slug/` — um capítulo por pasta
- `shared/` — design system (CSS + JS) compartilhado
- `context/` — documentação viva do projeto (SDD) — **comece por aqui**
- `assets/` — imagens, logos, memes, SVGs

## Conteúdo
HTML & CSS → JavaScript → DOM/eventos → React (Vite, componentes, props, hooks) → React Router
→ json-server → integração com a API real (Axios + JWT).

Veja o mapa completo em [`context/04-conteudo-curso.md`](context/04-conteudo-curso.md).
