# context/ — Memória viva do projeto (SDD)

Esta pasta guarda o **contexto de design e didática** do material de Frontend do curso
Fullstack. Antes de criar ou editar qualquer capítulo, leia os docs relevantes aqui.
A ideia (Spec-Driven Development) é simples: **nunca perder o contexto** — qualquer pessoa
(ou IA) que abrir o projeto consegue continuar do mesmo jeito.
