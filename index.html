Aula 00 — O que é ser Fullstack? 🎮

Antes do código: a analogia do restaurante, a torre da stack, o joguinho "Dev Run" pra caminhar pelas tecnologias e o ciclo de uma requisição (front → API → Java → banco → tela). Perfeito pra entender o mapa inteiro.

🔌 Como front e back conversam

O navegador (front) faz um pedido ("me dá a lista de clientes"). A API (back) responde com os dados. Você vai ver isso acontecer ao vivo nos últimos capítulos.
