Desafio: a Lanchonete 🍔

Nenhum conceito novo. Você vai montar um cardápio de lanchonete do zero, sozinho(a), usando tudo o que treinou na Mini-loja dos Caps 4 e 5: componentes, props, .map() e imagens. É o teste de fogo: sem o prof do lado, o código sai?

⚛️ componentes 🎁 props 🏭 .map() + key 🖼️ imagens 🧹 faxina no CSS
🎯
A missão
O que você vai entregar no fim deste capítulo
👨‍🍳 Cozinhar sem olhar a receita

Na Mini-loja, o prof cozinhou junto com você. Agora a cozinha é sua: mesmo prato, ingredientes novos. Se travar em algum passo, tudo bem — é exatamente aí que o aprendizado acontece. A receita (👀) existe, mas só depois de você tentar.

Você vai criar um projeto React novo chamado lanchonete, com:

  • Um Banner com duas imagens — uma vinda da pasta public/ e outra importada de src/assets/ (os dois caminhos do Cap 5).
  • Um Cabecalho dando boas-vindas à lanchonete.
  • Um CartaoLanche que recebe nome, preco e descricao por props.
  • Um array lanches com 4 lanches, virando cards na tela com .map() e key.
  • index.css e App.css completamente vazios — a página fica "crua" de propósito (o visual é bônus).

A estrutura final de pastas — repare na novidade pequena, a pasta src/components/ guardando os componentes (organização de projeto de verdade):

Passo 2 — a faxina (sozinho/a)
App.jsx enxuto + index.css e App.css VAZIOS
★ fácilboilerplateCSS limpo
💡 Dica

O Vite entrega o projeto cheio de exemplo. Sua faxina tem 3 alvos, todos dentro de src/:

1. App.jsx — apague tudo e recrie com o rafce, devolvendo só uma <div> com um <h1> qualquer (pra testar).
2. App.css — abra, selecione tudo (Ctrl/Cmd + A), apague, salve. O arquivo fica vazio.
3. index.css — mesma coisa: conteúdo zero.

É o CSS de exemplo do Vite que deixa o fundo escuro e centraliza tudo — limpando os dois, a página volta a ser uma folha em branco.

⚠️
Apague o conteúdo, não os arquivos! O main.jsx importa o index.css e o App.jsx pode importar o App.css — se o arquivo sumir, o import quebra e a tela fica branca. Vazio ≠ deletado.
🚨
Tenta antes! Se o rafce colocar um import React from 'react' no topo, pode apagar essa linha — o Vite moderno dispensa.
👀 Só clique aqui DEPOIS de tentar — Ver solução▼
src/App.jsxJSX
const App = () => {
  return (
    <div>
      <h1>Lanchonete no ar!</h1>
    </div>
  )
}

export default App

Passo 4 — o CartaoLanche com props (sozinho/a)
O molde que vai carimbar o cardápio inteiro
★★ médiopropsdesestruturação
💡 Dica

Crie src/components/CartaoLanche.jsx recebendo 3 props desestruturadas: nome, preco e descricao. Ele devolve uma <div> com três <p>, um pra cada informação. Pra testar, use um card na mão no App.jsx, abaixo do <h1> — invente um lanche! Lembre: texto entre aspas, número entre chaves.

🚨
Tenta antes! A desestruturação é aquele abraço de chaves nos parênteses: ({ nome, preco, descricao }).

const CartaoLanche = ({ nome, preco, descricao }) => {

}

export default CartaoLanche

Passo 5 — o array e a esteira do .map() (sozinho/a)
4 lanches entram, 4 cards saem — sem copiar e colar
★★ médio.map()key
💡 Dica

No App.jsx, crie (fora do componente) um array lanches com 4 objetos, cada um com id, nome, preco e descricao. Depois apague o card de teste do Passo 4 e gere a lista com lanches.map(...), passando as três props a partir de cada item — e a key={l.id}, senão o React reclama no console!

🚨
Tenta antes! Leia em voz alta: "para cada lanche l da lista, devolva um <CartaoLanche> com os dados dele".
👀 Só clique aqui DEPOIS de tentar — Ver solução▼
src/App.jsxJSX
import Cabecalho from './components/Cabecalho'
import CartaoLanche from './components/CartaoLanche'

const lanches = [
  { id: 1, nome: "X-Burger", preco: 18, descricao: "Pão, carne e queijo" },
  { id: 2, nome: "X-Salada", preco: 22, descricao: "Alface, tomate e maionese da casa" },
  { id: 3, nome: "X-Bacon", preco: 26, descricao: "Bacon crocante em dobro" },
  { id: 4, nome: "Batata Frita", preco: 12, descricao: "Porção média bem sequinha" },
]

const App = () => {
  return (
    <div>
      <Cabecalho />
      <h1>Cardápio:</h1>
      {lanches.map((l) => (
        <CartaoLanche key={l.id} nome={l.nome} preco={l.preco} descricao={l.descricao} />
      ))}
    </div>
  )
}

export default App
✅
Teste a esteira: adicione um 5º lanche no array (com id: 5!), salve, e veja o card aparecer sem tocar no JSX. É por isso que o .map() existe.
👻 Pegadinha rápida: um colega adicionou ao array um lanche sem o campo descricao, mas o .map() continua passando descricao={l.descricao}. O que aparece naquele card?

Passo 6 — o Banner com as duas imagens (sozinho/a)
Uma da public/, outra importada de src/assets — os dois caminhos do Cap 5
★★★ desafiopublic/import de assets
💡 Dica

Escolha duas imagens (baixe da internet — um hambúrguer, um logo, o que quiser):

1. Salve uma como banner.png dentro de public/ → no JSX ela entra com src="/banner.png" (caminho começando com barra, sem import).
2. Crie a pasta src/assets/ (se o Vite já não criou), salve a outra como logo.png → essa entra com import + src={logo}.

Monte tudo num componente Banner.jsx (em components/!) e use no App acima do Cabecalho. Dê um width nas imagens pra não explodirem a tela.

🧭
Atenção ao caminho do import dentro do Banner.jsx: ele mora em src/components/, e a imagem em src/assets/ — ou seja, o caminho sobe um nível: '../assets/logo.png' (dois pontos = "sai da pasta components").
🚨
Tenta antes! Se a imagem aparecer "quebrada" 🧩, revise: a da public/ usa barra e aspas; a de assets usa import e chaves. Misturou? Não funciona.
👀 Só clique aqui DEPOIS de tentar — Ver solução▼
src/components/Banner.jsxJSX
import logo from '../assets/logo.png'

const Banner = () => {
  return (
    <div>
      <img src="/banner.png" width="150" />   {/* veio da public/ */}
      <img src={logo} width="150" />          {/* veio do import */}
    </div>
  )
}

export default Banner
src/App.jsx (topo + começo do return)JSX
import Banner from './components/Banner'
// ...os outros imports continuam aqui

return (
  <div>
    <Banner />
    <Cabecalho />
    {/* ...o resto continua igual */}
  </div>
)

Conferência final
Se marcou tudo, você domina o básico do React
  • Projeto do zero: criou com Vite, limpou o boilerplate e deixou index.css + App.css vazios (sem deletar os arquivos!).
  • Componentes organizados: Banner, Cabecalho e CartaoLanche morando em src/components/, cada um com seu export default.
  • Props na veia: texto entre aspas, número/JS entre chaves, desestruturação nos parênteses.
  • .map() + key: o array manda, a tela obedece — 4 lanches ou 40, o código é o mesmo.
  • Imagens pelos dois caminhos: public/ com "/banner.png" e src/assets/ com import + {logo}.
