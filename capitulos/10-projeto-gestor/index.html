Os 4 verbos do HTTP (a teoria nova do capítulo)
Até hoje você só PEDIA dados. Hoje aprende a criar, trocar e apagar

Hora da única teoria realmente nova do projeto — e ela é deliciosa de simples. Desde o Cap 7, toda conversa sua com a API foi axios.get(...): GET é o verbo de pedir para ler. Mas o HTTP tem outros verbos, e um sistema de gestão usa os 4 principais:

🏤 O balcão do cartório

Pensa no json-server como um cartório com um arquivo de fichas (o db.json). Você chega no balcão e o VERBO do seu envelope diz o que quer fazer: GET = "me mostra as fichas" (só leitura, nada muda) · POST = "registra esta ficha NOVA" (o cartório carimba um id novo) · PUT = "TROCA a ficha de número X por esta aqui" (por isso a URL leva o id!) · DELETE = "rasga a ficha de número X". Mesmo balcão, mesmo endereço — o verbo muda tudo.

No axios, cada verbo é um método com a mesma cara do get que você já usa:

a família completa do axiosJS
// LER a lista (o velho conhecido do Cap 7):
axios.get("http://localhost:3000/clientes")

// CRIAR: o 2º argumento é o objeto com os dados da ficha nova
// (repare: SEM id — quem carimba o id é o servidor!)
axios.post("http://localhost:3000/clientes", { nome: "Diego", cidade: "Patos" })

// TROCAR: o id vai na URL (QUAL ficha) e o objeto novo vai no 2º argumento
axios.put("http://localhost:3000/clientes/2", { nome: "Bruno Lima", cidade: "Sousa" })

// APAGAR: só a URL com o id — não tem "corpo", só o alvo
axios.delete("http://localhost:3000/clientes/3")
📛 O nome de mercado: CRUD

Esse quarteto tem apelido famoso: CRUD — Create (POST), Read (GET), Update (PUT), Delete (DELETE). Quando uma vaga pedir "experiência com CRUD", é ISSO: cadastrar, listar, editar e excluir. Ao fim de hoje, você terá feito um CRUD triplo — pode escrever no currículo sem corar. 😄

Brinca de cartório: mande cada verbo e repare no que acontece com o db.json (e no que NÃO acontece) 👇

src/pages/Clientes.jsx — versão 1 (só listar)JSX
import { useState, useEffect } from "react"
import axios from "axios"
import styles from "./Clientes.module.css"

const Clientes = () => {
  const [clientes, setClientes] = useState([])
  const [carregando, setCarregando] = useState(true)
  const [erro, setErro] = useState(false)

  useEffect(() => {
    axios.get("http://localhost:3000/clientes")
      .then((res) => {
        setClientes(res.data)
        setCarregando(false)
      })
      .catch(() => {
        setErro(true)
        setCarregando(false)
      })
  }, [])

  if (carregando) { return <p>⏳ Carregando clientes...</p> }
  if (erro) { return <p>😵 Não consegui falar com o servidor. Ele está de pé?</p> }

  return (
    <div className={styles.pagina}>
      <h2>👥 Clientes</h2>
      <table className={styles.tabela}>
        <thead>
          <tr>
            <th>Nome</th><th>E-mail</th><th>Telefone</th><th>Cidade</th>
          </tr>
        </thead>
        <tbody>
          {clientes.map((c) => (
            <tr key={c.id}>
              <td>{c.nome}</td>
              <td>{c.email}</td>
              <td>{c.telefone}</td>
              <td>{c.cidade}</td>
            </tr>
          ))}
        </tbody>
      </table>
    </div>
  )
}

export default Clientes

Agora a tela /clientes/novo: um formulário controlado (Cap 6 — um useState por campo, value + onChange) que, ao salvar, manda um POST e volta pra listagem. E aqui entra a 2ª novidade honesta do capítulo:

🧭 useNavigate — o Link que acontece via código

O <Link> navega quando o usuário clica. Mas depois de salvar, quem decide voltar pra listagem é o seu código — dentro do .then(), quando o servidor confirmar. Pra isso o Router dá um hook irmão do useParams: o useNavigate. Você chama const navigate = useNavigate() no topo (mesma cerimônia dos outros hooks) e ganha uma função: navigate("/clientes") = "vá para /clientes agora". É um Link programável — nada além disso.

import { useState } from "react"
import { useNavigate } from "react-router-dom"
import axios from "axios"
import styles from "./ClienteNovo.module.css"

const ClienteNovo = () => {
  const [nome, setNome] = useState("")
  const [email, setEmail] = useState("")
  const [telefone, setTelefone] = useState("")
  const [cidade, setCidade] = useState("")
  const navigate = useNavigate()

  const salvar = () => {
    if (nome === "") {
      alert("O nome é obrigatório!")
      return   // o porteiro do Cap 8: para aqui, nem chama a API
    }
    axios.post("http://localhost:3000/clientes", {
      nome: nome,
      email: email,
      telefone: telefone,
      cidade: cidade
    })
      .then(() => navigate("/clientes"))   // salvou? volta pra lista
  }

  return (
    <div className={styles.pagina}>
      <h2>➕ Novo cliente</h2>
      <input placeholder="Nome" value={nome} onChange={(e) => setNome(e.target.value)} />
      <input placeholder="E-mail" value={email} onChange={(e) => setEmail(e.target.value)} />
      <input placeholder="Telefone" value={telefone} onChange={(e) => setTelefone(e.target.value)} />
      <input placeholder="Cidade" value={cidade} onChange={(e) => setCidade(e.target.value)} />
      <button onClick={salvar}>💾 Salvar</button>
    </div>
  )
}

export default ClienteNovo

Clientes: excluir fase 1 · na mão
DELETE + o conceito-mor: servidor e tela são dois mundos

Excluir é o verbo mais perigoso do balcão — então todo sistema decente pergunta antes. Pra isso usamos o window.confirm: o primo do alert que você conhece desde o Cap 3, só que com pergunta — ele abre a caixinha "OK / Cancelar" e devolve true ou false (um boolean, Cap 2!). Perfeito pra um if.

confirm → axios.delete → atualizar o estado com .filter()
🎯 Tarefa

Na Clientes.jsx: 1) crie a função excluir (abaixo). 2) Na tabela, uma coluna nova "Ações" com o botão em cada linha. 3) Teste: excluir a Carla → confirmar → ela some da tela E do db.json.

src/pages/Clientes.jsx — a função e o botão novosJSX
// dentro do componente, junto dos estados:
const excluir = (id) => {
  if (window.confirm("Tem certeza que quer excluir este cliente?")) {
    axios.delete("http://localhost:3000/clientes/" + id)
      .then(() => {
        // o servidor já rasgou a ficha — agora avisamos a TELA:
        setClientes(clientes.filter((c) => c.id !== id))
      })
  }
}

// e na tabela, a célula nova em cada linha do .map():
<td>
  <button onClick={() => excluir(c.id)}>🗑️ Excluir</button>
</td>
🌍 O conceito-mor do CRUD: dois mundos

Olha o .then() com carinho, porque ele carrega A lição do capítulo: o axios.delete apaga a ficha no servidor — mas a tela mostra o estado, que é outro mundo (é a cópia que o useEffect trouxe lá no início). Se você não atualizar o estado, o cliente excluído continua na tela até o próximo F5 — o sistema fica parecendo quebrado sem estar. Por isso o setClientes(clientes.filter(...)): o .filter (Cap 2/6!) monta uma lista nova sem o excluído — repare no !==, "ficam só os que NÃO têm esse id" — e o set redesenha. Servidor atualizado + estado atualizado = os dois mundos em paz.

🎯
E o onClick={() => excluir(c.id)}? É a arrow inline do Cap 6 — precisamos passar o id do cliente DAQUELA linha, então embrulhamos a chamada numa função. Sem o embrulho (onClick={excluir(c.id)}) ela executaria na renderização — a pegadinha clássica.

import { useState, useEffect } from "react"
import { useParams, useNavigate } from "react-router-dom"
import axios from "axios"
import styles from "./ClienteNovo.module.css"   // mesmo visual do cadastro — reuso!

const ClienteEditar = () => {
  const { id } = useParams()
  const navigate = useNavigate()
  const [nome, setNome] = useState("")
  const [email, setEmail] = useState("")
  const [telefone, setTelefone] = useState("")
  const [cidade, setCidade] = useState("")

  useEffect(() => {
    // busca a ficha atual e PRÉ-ENCHE o formulário:
    axios.get("http://localhost:3000/clientes/" + id)
      .then((res) => {
        setNome(res.data.nome)
        setEmail(res.data.email)
        setTelefone(res.data.telefone)
        setCidade(res.data.cidade)
      })
  }, [id])

  const salvar = () => {
    axios.put("http://localhost:3000/clientes/" + id, {
      nome: nome,
      email: email,
      telefone: telefone,
      cidade: cidade
    })
      .then(() => navigate("/clientes"))
  }

  return (
    <div className={styles.pagina}>
      <h2>✏️ Editar cliente</h2>
      {/* os MESMOS 4 inputs controlados do cadastro */}
      <input placeholder="Nome" value={nome} onChange={(e) => setNome(e.target.value)} />
      <input placeholder="E-mail" value={email} onChange={(e) => setEmail(e.target.value)} />
      <input placeholder="Telefone" value={telefone} onChange={(e) => setTelefone(e.target.value)} />
      <input placeholder="Cidade" value={cidade} onChange={(e) => setCidade(e.target.value)} />
      <button onClick={salvar}>💾 Salvar alterações</button>
    </div>
  )
}

export default ClienteEditar

src/pages/Dashboard.jsxJSX
import { useState, useEffect } from "react"
import { Link } from "react-router-dom"
import axios from "axios"
import styles from "./Dashboard.module.css"

const Dashboard = () => {
  const [clientes, setClientes] = useState([])
  const [fornecedores, setFornecedores] = useState([])
  const [produtos, setProdutos] = useState([])

  useEffect(() => {
    axios.get("http://localhost:3000/clientes").then((res) => setClientes(res.data))
    axios.get("http://localhost:3000/fornecedores").then((res) => setFornecedores(res.data))
    axios.get("http://localhost:3000/produtos").then((res) => setProdutos(res.data))
  }, [])

  const estoqueBaixo = produtos.filter((p) => p.estoque < 5).length

  return (
    <div className={styles.painel}>
      <h2>📊 Visão geral</h2>
      <div className={styles.cards}>
        <Link to="/clientes" className={styles.card}>
          <strong>{clientes.length}</strong> 👥 clientes
        </Link>
        <Link to="/fornecedores" className={styles.card}>
          <strong>{fornecedores.length}</strong> 🚚 fornecedores
        </Link>
        <Link to="/produtos" className={styles.card}>
          <strong>{produtos.length}</strong> 📦 produtos
        </Link>
      </div>
      {estoqueBaixo > 0 && (
        <p className={styles.alerta}>⚠️ {estoqueBaixo} produtos com estoque baixo</p>
      )}
    </div>
  )
}

export default Dashboard

Os 5 tropeços clássicos do projeto — dois deles vêm do agente

Bug 1 — o F5 revelador: excluiu, o servidor apagou… mas a tela só muda no F5. Faltou o set no .then() — servidor e estado são dois mundos, e você só atualizou um. Conserto: setClientes(clientes.filter((c) => c.id !== id)) dentro do then.

🐛
Bug 3 — o PUT sem endereço: axios.put("/fornecedores", ...) sem o /id → 404 na cara. PUT troca UMA ficha; a URL tem que dizer QUAL. Conserto: "http://localhost:3000/fornecedores/" + id. Leia toda URL de PUT/DELETE como um endereço de casa: sem número, o carteiro não entrega.
🐛
Bug 4 — o agente rebelde: o diff veio com react-hook-form, useRef ou um fetch perdido — tudo proibido no AGENTS.md. Conserto: não é consertar na mão, é reprovar citando a regra: "refaça seguindo o AGENTS.md — formulário controlado com useState, como o módulo Clientes". O arquivo de regras só protege quem o usa na revisão.
