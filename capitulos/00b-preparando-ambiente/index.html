Preparando o ambiente

Toda obra começa pelas ferramentas certas 🛠️

Antes de escrever a primeira linha, vamos montar o seu "estúdio" de programação: instalar o VSCode, organizar as pastas e ativar as extensões que vão deixar tudo mais fácil, bonito e rápido.

🧑‍🍳
Por que perder tempo com isso?
Ferramenta boa é meio caminho andado
A cozinha do chef 👨‍🍳

Nenhum chef começa a cozinhar com a cozinha bagunçada e sem facas afiadas. Ele prepara o ambiente primeiro: organiza os ingredientes, separa as panelas, afia a faca.

Programar é igual. Um ambiente bem montado faz você codar mais rápido, errar menos e se divertir mais. Vamos montar o seu agora — é rapidinho e vale pra todos os sábados que vêm.

😌
Calma, é tranquilo. Você faz isso uma vez só e está pronto pro curso inteiro — front e back. Se travar em algo, chama o prof. 🙋
1. Instalando o VSCode
Nosso editor de código — gratuito e o mais usado do mundo
💡 O que é o VSCode?

É um editor de código — tipo um "Word" para programadores, mas muito mais esperto: ele colore o código, avisa erros, completa o que você digita e roda extensões. Feito pela Microsoft, gratuito, e o queridinho do mercado.

  1. Passo 1: acesse code.visualstudio.com
  2. Passo 2: clique no botão grande de download (ele detecta seu sistema: Windows, Mac ou Linux)
  3. Passo 3: instale como qualquer programa (next, next, finish 😄)
  4. Passo 4: abra o VSCode. Apareceu uma tela de boas-vindas? Deu certo! 🎉
⚠️
Não confunda: "VSCode" (Visual Studio Code) é diferente de "Visual Studio" (sem o Code). A gente quer o Code — o leve, azul-clarinho.
📁
2. Organizando as pastas do curso
Lugar pra cada coisa, cada coisa no seu lugar
O armário organizado 🗄️

Imagina jogar todas as suas roupas numa pilha só. Caos, né? Com código é igual: a gente cria pastas pra organizar. Vamos criar a estrutura do curso:

Crie (no seu computador) uma pasta principal e, dentro dela, uma por aula:

explorador de arquivos
📁 curso_fullstack_em_sala
📁 aula01
📁 aula02
📁 ...
// uma pasta pra cada sábado
// tudo organizado e fácil de achar 👌
⌨️ O atalho mágico: code .

Você pode abrir uma pasta no VSCode pelo terminal. Dentro da pasta da aula, digite code . (o ponto significa "esta pasta aqui"). O VSCode abre já apontando pra ela.

Não curte terminal? Sem problema: VSCode → Arquivo → Abrir Pasta e escolha a pasta. Dá no mesmo. 😉

📛
Nomes de pastas e arquivos: sem espaços, sem acento, tudo minúsculo, usando _ no lugar do espaço. aula01 ✅   Aula 01 ❌. Programador evita dor de cabeça com nomes simples.
🧩
3. As 5 extensões que eu recomendo
Pra abrir: ícone de "peças" 🧩 na barra lateral → busque pelo nome → Install

Extensões são "plugins" que turbinam o VSCode. Essas 5 eu recomendo em todas as turmas:

🌐
Open Browser Preview
por Eno Yao
Mostra a pré-visualização da sua página HTML dentro do VSCode, sem precisar ficar trocando de janela. Essencial pro nosso começo com HTML/CSS.
1
🎨
Material Icon Theme
por Philipp Kief
Coloca ícones bonitos em cada tipo de arquivo e pasta. Bate o olho e já sabe o que é HTML, CSS, JS, imagem… Deixa tudo mais fácil de achar.
2
⚛️
ES7+ React/Redux/React-Native snippets
por dsznajder
Atalhos que escrevem código React pra você (digita rafce + Tab e nasce um componente inteiro). Vamos usar lá na frente, mas já deixa instalado.
3
▶️
Code Runner
por Jun Han
Roda seu código com um clique (ou Ctrl/Cmd + Alt + N). Ótimo pra testar trechos de JavaScript rapidinho.
4
🧛
Dracula Official (tema)
tema de cores — gosto pessoal
Um tema escuro roxinho que deixa o editor lindo e descansa a vista. Opcional! Use o tema que te deixar feliz — codar bonito anima. 🧛‍♂️
5
💜
Pra ativar um tema: Ctrl/Cmd + K e depois Ctrl/Cmd + T, escolha o Dracula. Ou: Arquivo → Preferências → Tema de Cores.
🧪
4. Teste relâmpago: sua primeira página
Só pra confirmar que tudo funciona (com o prof)
👨‍🏫
Crie index.html e veja a mágica
Dentro da pasta aula01
  1. No VSCode, com a pasta aula01 aberta, crie um arquivo: botão de novo arquivo → nome index.html
  2. Clique dentro do arquivo, digite só ! e aperte Tab — o VSCode cospe a estrutura HTML inteira (isso se chama Emmet 🪄)
  3. Entre as tags <body>, escreva: <h1>Funcionou! 🎉</h1>
  4. Salve com Ctrl/Cmd+S
  5. Clique direito no arquivo → "Open Browser Preview" (ou "Open with Live Server") e veja na tela!
✨
Viu "Funcionou! 🎉" aparecer? Seu ambiente está pronto. A partir do próximo capítulo, é só alegria (e código). 🚀
