src/br/com/gestorpro/Produto.javaarquivo completo
package br.com.gestorpro;

public class Produto {
    private Long id;
    private String nome;
    private double preco;
    private int estoque;

    public Produto(String nome, double preco, int estoque) {
        this.nome = nome;
        setPreco(preco);
        setEstoque(estoque);
    }

    public Long getId() { return id; }
    public void setId(Long id) { this.id = id; }
    public String getNome() { return nome; }
    public void setNome(String nome) { this.nome = nome; }
    public double getPreco() { return preco; }
    public void setPreco(double preco) {
        if (preco < 0) {
            System.out.println("Preço inválido");
            return;
        }
        this.preco = preco;
    }
    public int getEstoque() { return estoque; }
    public void setEstoque(int estoque) {
        if (estoque < 0) {
            System.out.println("Estoque inválido");
            return;
        }
        this.estoque = estoque;
    }
    @Override
    public String toString() {
        return "#" + id + " " + nome + " - R$ " + preco
                + " (estoque: " + estoque + ")";
    }
}
O this sem mistério

Em this.nome = nome, this.nome é o campo do objeto atual; nome é o valor que chegou ao construtor.

📨 O que entra e o que volta de um método?

Argumento é o valor enviado na chamada. Parâmetro é o nome que recebe esse valor dentro do método. this indica o objeto atual; return devolve o resultado a quem chamou. Devolver não é imprimir: isso é trabalho de println. Um método void não devolve um valor.

A oficina começa com Produto fone = new Produto("Fone", 80.0, 2); já executado. Usaremos esse mesmo objeto nas duas chamadas.

🪪 O nome não é o objeto

Uma variável como fone guarda uma referência: um caminho para alcançar o objeto. Dois new criam objetos distintos. Já Produto apelido = fone; copia a referência: dois nomes chegam ao mesmo objeto. Vamos visualizar antes de digitar?

Dinheiro real: usamos double apenas para manter a primeira aula simples. No projeto Spring, preço será tratado com BigDecimal.

ProdutoService: os verbos do cadastro
Uma lista em memória e quatro operações
🧑‍💼 O gerente do cadastro

Produto sabe cuidar de seus próprios dados. ProdutoService sabe organizar o conjunto: cadastrar, listar, buscar e remover.

List<Produto> significa “uma lista cujo item é Produto”. ArrayList é a implementação que usaremos para guardar os objetos enquanto o programa está rodando.

src/br/com/gestorpro/ProdutoService.javaarquivo completo
package br.com.gestorpro;

import java.util.ArrayList;
import java.util.List;

public class ProdutoService {
    private final List<Produto> produtos = new ArrayList<>();
    private long proximoId = 1;

    public Produto cadastrar(Produto produto) {
        produto.setId(proximoId++);
        produtos.add(produto);
        return produto;
    }

    public List<Produto> listar() {
        return produtos;
    }

    public Produto buscarPorId(Long id) {
        for (Produto produto : produtos) {
            if (produto.getId().equals(id)) {
                return produto;
            }
        }
        return null;
    }

    public boolean remover(Long id) {
        Produto produto = buscarPorId(id);
        if (produto == null) {
            return false;
        }
        return produtos.remove(produto);
    }
}

Por que equals no id?

Long é um objeto. Para comparar o valor de dois objetos, usamos equals. O == continua útil aqui para conferir se uma referência é null.

package br.com.gestorpro;

public class Main {
    public static void main(String[] args) {
        ProdutoService service = new ProdutoService();
        Produto teclado = new Produto("Teclado Mecânico", 320.0, 12);
        Produto mouse = new Produto("Mouse Gamer", 89.0, 5);
        service.cadastrar(teclado);
        service.cadastrar(mouse);

        System.out.println("=== PRODUTOS ===");
        for (Produto produto : service.listar()) {
            System.out.println(produto);
        }

        Produto encontrado = service.buscarPorId(2L);
        if (encontrado != null) {
            System.out.println("Encontrado: " + encontrado.getNome());
        }
        boolean removeu = service.remover(1L);
        System.out.println("Removeu #1? " + removeu);
        System.out.println("Restaram: " + service.listar().size());
    }
}
