O que é JavaScript?
A linguagem que dá vida às páginas
⚡ A parte elétrica da casa

HTML montou as paredes. CSS pintou tudo. Mas a casa ainda está "morta" — nada acontece. O JavaScript é a parte elétrica: o interruptor que acende a luz, a campainha que toca, o portão que abre quando você aperta o botão.

É o JS que faz: o botão reagir ao clique, o carrinho de compras somar, a mensagem "senha incorreta" aparecer, os dados virem do servidor e preencherem a tela.

🙅
JavaScript ≠ Java. Apesar do nome, não têm relação direta. JS nasceu pra deixar páginas web interativas e hoje é uma das linguagens mais usadas do mundo — roda no navegador e no servidor (Node.js).
🤓
Curiosidades que vão te impressionar
A história maluca da linguagem mais usada da web
  • 🚀 O JavaScript foi criado em apenas 10 dias, em 1995, por Brendan Eich na Netscape. Dez dias! E hoje roda metade da internet. 🤯
  • 🎭 O nome "JavaScript" foi marketing: na época o Java estava na moda, então pegaram carona no nome. São linguagens diferentes (a gente já falou disso!).
  • 🌍 É usado por Netflix, Airbnb, Instagram, WhatsApp e praticamente todo site grande que você acessa.
  • ⚡ É interpretado: não precisa "compilar" antes — o navegador lê e executa na hora. Por isso é tão rápido de testar.
  • 🧰 Roda no navegador e no servidor (com Node.js). É o canivete suíço da programação web.

Node.js — rodando JavaScript no seu computador
Pra testar seus arquivos .js direto no VSCode
O JS saiu do navegador 🚪

Por muito tempo, o JavaScript só rodava dentro do navegador. Aí criaram o Node.js: um programa que executa JavaScript direto no seu computador (e nos servidores!). É graças a ele que dá pra rodar um arquivo .js sem abrir o navegador.

📥 Instalando o Node

Acesse nodejs.org e baixe a versão LTS (a "estável", recomendada). Instale como qualquer programa. Pra conferir, abra o terminal e digite node -v — se aparecer um número de versão (ex.: v20.x), funcionou! 🎉

terminalbash
# confere se o Node está instalado
node -v
# roda um arquivo JavaScript
node meu_arquivo.js
▶️
Atalho no VSCode: com a extensão Code Runner instalada (lembra da aula de setup?), é só apertar Ctrl/Cmd + Alt + N com o arquivo aberto que ele roda e mostra o resultado ali embaixo. Sem terminal, sem complicação. 😎
🔮
Calma com o Node! Por enquanto a gente só usa ele pra rodar nossos arquivos de treino. No capítulo inicial de React eu explico direitinho o que o Node faz por trás (npm, pacotes, servidor de desenvolvimento). Por agora, é só o nosso "play" de JavaScript. ▶️

Uma variável é uma caixinha com nome onde você guarda um valor pra usar depois. Você dá um nome (a etiqueta) e coloca algo dentro.

💡 let ou const?

Regra de bolso: use const por padrão. Só troque pra let quando souber que o valor vai mudar. (Existe o var antigo — esqueça, ninguém usa mais.)

🧠 Rapidinha: o que acontece aqui? const pi = 3.14; pi = 3.15;

🚦
Reparou no media = 7? Deu Aprovado, porque >= é "maior ou igual" — o 7 em ponto passa raspando. Detalhe de operador muda o destino!
⚖️
Compare com === (três iguais), não com ==. O === compara valor e tipo, do jeito que você espera. O == faz "conversões mágicas" que confundem (ex.: 0 == "" dá true!). Regra: sempre ===.
🤓 Por que 0.1 + 0.2 não dá 0.3?

Computadores guardam decimais em binário, e alguns números "não fecham" — sobra uma casquinha (0.30000000000000004). Isso acontece em quase toda linguagem, não só JS. Por enquanto, só saiba que existe — a gente lida com isso quando aparecer.

Operadores — as ferramentas de cálculo e comparação
Símbolos que fazem contas e comparações
🧮 Aritméticos (fazem conta)

+ soma · - subtrai · * multiplica · / divide · % resto da divisão (o "módulo")

⚖️ Comparação (devolvem true/false)

=== igual · !== diferente · > maior · < menor · >= maior ou igual · <= menor ou igual

🔗 Lógicos (combinam condições)

&& "E" (as duas verdadeiras) · || "OU" (pelo menos uma) · ! "NÃO" (inverte)

📥 Atribuição (guardam valor)

= guarda · += soma e guarda (x += 1 é x = x + 1)

🤔
O misterioso % (módulo): dá o resto de uma divisão. 10 % 2 é 0 (par!), 7 % 2 é 1 (ímpar!). É o truque pra saber se um número é par ou ímpar. Guarda essa. 😉

Funções: empacotando código pra reusar
Inclui a "arrow function" — você vai ver MUITO ela no React
🍳 Uma receita

Uma função é uma receita: você dá um nome, define os ingredientes (parâmetros) e o que ela devolve (return). Depois é só "chamar" quantas vezes quiser, sem reescrever tudo.

funcoes.jsJavaScript
// jeito clássico
function saudacao(nome) {
  return `Olá, ${nome}!`;
}

// chamando a função
console.log(saudacao("Maria"));  // Olá, Maria!

Existe uma forma mais curta, a arrow function (função-seta). É a queridinha do React:

arrow.jsJavaScript
const saudacao = (nome) => {
  return `Olá, ${nome}!`;
};

// versão curtíssima (return implícito):
const dobro = (n) => n * 2;
console.log(dobro(5));  // 10
⌨️
Atenção, isso é importante: aquela seta => é digitada com dois caracteres: o sinal de igual = seguido do maior que >. A sua IDE (VSCode) pode desenhar isso como uma setinha bonita ⇒, mas você nunca digita o símbolo — sempre = e >.

Pensa na função como uma máquina de fábrica: o valor entra pelo funil (é o argumento), a máquina trabalha com ele (o parâmetro n), e o resultado sai pela rampa (o return). Aperta um botão e olha o número viajar: 👇

⚙️⚙️⚙️
const dobro = (n) => n * 2
 
💡 Argumento × parâmetro × return

O 5 que você manda é o argumento. Dentro da máquina ele atende pelo nome n — o parâmetro. E o que sai pela rampa é o return. Mesma máquina, entradas diferentes, saídas diferentes — sem reescrever nada. Essa é a graça das funções.

Arrays e Objetos
As duas estruturas que vão te seguir até o React

Array = uma lista ordenada (uma fila de coisas). Objeto = uma ficha com pares chave: valor (como o cadastro de uma pessoa).

colecoes.jsJavaScript
// ARRAY: lista entre colchetes [ ]
const frutas = ["maçã", "uva", "manga"];
console.log(frutas[0]);      // maçã (começa no ZERO!)
frutas.push("pera");       // adiciona no fim

// OBJETO: pares chave: valor entre chaves { }
const cliente = {
  nome: "João",
  idade: 30,
  ativo: true
};
console.log(cliente.nome);    // João

Um array é um trem de carga 🚂: cada vagão tem uma placa com o índice — e a contagem começa no 0. Clica nos botões e observa o trem:

frutas.length = 3
🚂
🐛
Arrays começam no índice 0! O primeiro item é frutas[0], o segundo é frutas[1]... Isso confunde todo mundo no começo. frutas[1] NÃO é a primeira fruta.
🔮
Por que isso importa tanto? No React, a tela quase sempre é uma lista de objetos virando elementos: uma lista de produtos, de clientes, de mensagens. Dominar array + objeto agora é investir direto no seu eu do futuro. 🚀

BugZilla ataca de novo!
Os tropeços clássicos de quem começa em JS
🐛
Bug 1 — chamar a função sem os parênteses. saudacao (só o nome) devolve a "receita". saudacao() (com parênteses) é que executa. Esqueceu o ()? A função não roda.
🐛
Bug 2 — usar == no lugar de ===. Comparações "mágicas" dão resultados bizarros. Use sempre os três iguais.
🐛
Bug 3 — "undefined" apareceu. Quase sempre é uma variável que você usou antes de criar, ou uma chave de objeto digitada errada (cliente.nme em vez de cliente.nome). Leia a mensagem do console — ela quase sempre aponta a linha!

Travou? Espalhe console.log() pelo código pra ver o valor de cada variável em cada ponto. 90% dos bugs morrem quando você enxerga o que está dentro das caixinhas.

Desafio Individual — desconto.js
Função que aplica desconto a um preço
💡 Dica pra fazer sozinho(a)

Crie uma função aplicarDesconto(preco, percentual) que devolve o preço final. Ex.: aplicarDesconto(100, 10) deve dar 90. Pense: o valor do desconto é preco * percentual / 100, e o final é preco menos isso. Teste no Console com console.log.

🚨
PARE! Tente sozinho(a) primeiro. Abra o Console, escreva, erre, ajuste. O aprendizado mora na tentativa!
👀 Só clique aqui DEPOIS de tentar — Ver solução ▼
desconto.jsJavaScript
function aplicarDesconto(preco, percentual) {
  const desconto = preco * percentual / 100;
  return preco - desconto;
}

console.log(aplicarDesconto(100, 10));  // 90
console.log(aplicarDesconto(250, 20));  // 200

// versão arrow, pra treinar a setinha =>
const aplicarDesconto2 = (preco, pct) => preco - (preco * pct / 100);

Bônus clássico — fizzbuzz.js 🏆
Um arquivo à parte — o exercício mais famoso de entrevista
★★★ desafiofor%&&
💡 Missão

Num arquivo novo fizzbuzz.js: imprima de 1 a 20, mas múltiplos de 3 viram "Fizz", de 5 viram "Buzz", e de 3 e 5 viram "FizzBuzz". Dica: use for e %. (Cai em entrevista de verdade! 😏)

🚨
Quebra a cabeça primeiro! Pensa na ordem dos if — o "FizzBuzz" tem que vir antes.
👀 Só clique aqui DEPOIS de tentar — Ver solução + console▼
fizzbuzz.jsJavaScript
for (let i = 1; i <= 20; i++) {
  if (i % 3 === 0 && i % 5 === 0) {
    console.log("FizzBuzz");
  } else if (i % 3 === 0) {
    console.log("Fizz");
  } else if (i % 5 === 0) {
    console.log("Buzz");
  } else {
    console.log(i);
  }
}
